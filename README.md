# Sky Pilot 3D

A 3D flight shooter that runs in the browser. Fly a propeller fighter through the sky and shoot down enemy planes and a heavy bomber boss.

**Play:** https://ayamaruko.github.io/sky-pilot-3d/

## Controls
- **Mobile:** drag anywhere to steer, hold the red FIRE button to shoot
- **PC:** arrow keys / WASD or mouse to fly, Space or mouse button to fire
- Pause: button at bottom left (or P / Esc)

Built with [three.js](https://threejs.org/).
